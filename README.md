# Study Journey

A 24-week study journey (Oct 12, 2026 – Mar 28, 2027) to become an expert in **Python, AI, and Cloud (AWS)**, plus **Blockchain**, daily **English** practice, and **LeetCode**.

## Daily routine
- **8:00–9:00 AM** – English (listening, reading, speaking, writing, flashcards)
- **2:00–3:00 PM** – Tech: 45 min main topic + 15 min LeetCode
